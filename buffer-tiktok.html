Acesso restrito

Entre com sua conta administradora no painel de redação e volte a esta página. O TikTok não é conectado sem autorização.

1. Conectar Buffer e TikTok

O Buffer é quem fará o envio à API oficial do TikTok. Use uma conta Buffer conectada ao TikTok do Giro Madeira.

1. Crie ou acesse Buffer e conecte o canal TikTok.
2. Gere uma chave em Settings → API do Buffer.
3. No Supabase, abra Edge Functions → Secrets e cadastre BUFFER_API_KEY com o valor da chave.

Mantenha a chave fora de prints e do chat. Ela nunca deve ser colocada no HTML nem no GitHub.

Aguardando verificação.

2. Selecionar exclusivamente o TikTok

Primeiro cadastre a chave de API no Supabase.

3. Testar com rascunho privado no Buffer

Vamos criar um rascunho que não é publicado usando um vídeo original já aprovado pelo Giro Madeira. Confira se o vídeo e a legenda aparecem corretamente no Buffer.

4. Ativação de publicações automáticas

A publicação ficará limitada a 5 vídeos por dia, com 90 minutos entre envios e sem repetir notícias. Confira no Buffer se o canal TikTok está no modo automático e se a programação de horários está configurada.

Até você confirmar o teste e ativar, nenhum vídeo será enviado automaticamente. Um vídeo só será contado como publicado depois da confirmação de envio do Buffer/TikTok.
